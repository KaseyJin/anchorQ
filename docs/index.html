AnchorQ · PDF 论文伴学

隐私政策

发布者：kasey · 生效日期：2026 年 9 月 6 日

AnchorQ 是用于 PDF 阅读期间注意力管理与理解检验的 Microsoft Edge 扩展。本政策说明扩展处理哪些数据、为什么处理，以及用户可以如何控制这些数据。

模型配置并非使用阅读器和网页守护功能的前提；未配置模型时，仅理解问答不可用。

AnchorQ 处理的数据

  • 当前学习会话所选 PDF 的地址、标题、页码和本地提取的文本层；
  • 用户实际阅读过的页码，以及为理解问答选取的少量论文片段；
  • 用户输入的学习目标、回答和后续问题；
  • 学习会话中目标标签页的 URL、标题和主机名，用于显示访问确认层。

AnchorQ 不处理的数据

AnchorQ 不读取普通网页正文、聊天内容、视频内容、密码、表单、摄像头、麦克风、剪贴板或 Edge 之外的应用活动。

不进行自动统计或错误上报

AnchorQ 第一版不集成使用统计、行为分析、广告追踪或崩溃上报服务，也不会在后台自动向发布者发送使用情况或错误信息。用户如需报告问题，可以主动联系支持邮箱，并自行决定提供哪些诊断信息。

用户选择的模型服务

AnchorQ 不内置公共模型账户。用户需要自行填写 OpenAI 兼容的 HTTPS 接口地址、模型名称和 API Key，并明确同意发送数据后，模型功能才会启用。

为完成出题和反馈，AnchorQ 会将学习目标、问答内容及必要的已读论文片段直接发送给用户选择的模型服务。AnchorQ 当前不部署中转服务器，也不控制第三方模型提供商。用户应自行查看相应提供商的隐私政策、数据保留规则和费用标准。

存储、保留和删除

  • 角色、确认模式、模型接口地址和模型名称保存在浏览器本地存储中；
  • API Key 仅保存在浏览器会话存储中，不向网页内容脚本开放，关闭 Edge 后清除；
  • 论文索引、活动许可和问答仅保留在当前浏览器会话中；
  • 用户可以随时在设置中清除模型凭据，或结束学习会话以删除当次索引和对话。

浏览器权限

  • storage：保存设置和当前学习会话；
  • tabs：识别当前 PDF、返回核心材料并判断标签页切换；
  • scripting 与按需网站访问：仅在用户授权并开始学习会话后安装访问确认层，会话结束后停止动态注册；
  • sidePanel：显示会话控制和伴学问答。
