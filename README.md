# AnchorQ

AnchorQ 是一个 Microsoft Edge Manifest V3 PDF 论文伴学扩展。它在学习会话中管理分心站点访问，并通过用户自行选择的 OpenAI 兼容模型检验理解。

## 环境

- Node.js 24+
- Microsoft Edge 114+
- Windows

## 安装依赖与构建

```powershell
npm install
npm run build
npm test
```

## 在 Edge 中加载

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目的 `dist` 目录。
5. 打开 AnchorQ 的扩展详情。
6. 开启“允许访问文件网址”。
7. 将 AnchorQ 固定到工具栏，点击图标打开 Side Panel。

## 配置模型

1. 打开 Side Panel 右上角的设置。
2. 填写 OpenAI 兼容 API 的 HTTPS 基础地址、模型名和自己的 API Key。
3. 阅读数据发送说明并勾选同意。
4. 点击“保存并测试”。

接口地址和模型名保存在 `chrome.storage.local`。API Key 仅保存在 `chrome.storage.session`，不会进入构建产物，关闭 Edge 后会自动清除。论文片段、学习目标与回答会直接发送给用户选择的模型服务，AnchorQ 当前不经过自有服务器。

## 使用流程

1. 在 Edge 中打开一份具有文本层的本地或公开 PDF。
2. 打开 AnchorQ Side Panel，可选填写本次学习目标并开始学习。
3. 首次启用网页守护时，通过 Edge 官方弹窗授予普通网站访问权限；该权限用于在目标网页显示前放置确认层。
4. Reader 在本地建立逐页文字索引，并记录实际阅读过的页码；PDF 原文不会整体发送给模型。
5. 切换到其他普通网页时，在防护层中选择返回、定时放行或本次会话放行。
6. 阅读结束后点击“结束并检查理解”。AnchorQ 从已读页面中选择少量相关证据，请模型生成问题。
7. 回答后，模型依据同一批证据反馈；若存在明确冲突，可标出回答原句并返回对应 PDF 页。

## 当前产品化限制

- 不处理浏览器快捷键。
- 不采集普通网页内容。
- 学习会话期间，未获许可的普通网页会被不透明防护层预先遮蔽；浏览器内部页面不在此范围内。
- 不实现 PDF 文字选择、批注、搜索或连续滚动。
- 不实现前台有效时间累计和主动到期复核。
- 不实现锁屏和浏览器重启恢复。
- 首版只支持具有文本层的 PDF；纯图片扫描件不做 OCR。
- 为控制本地存储和处理成本，单份 PDF 最多索引前 400 页且总计不超过 150 万字符，单页文字最多保留 12,000 字符；每次模型请求最多选择 6 页、14,000 字符。
- 模型服务由用户自行选择；其可用性、费用和数据处理政策由相应提供商负责。
- 浏览器内部页面、扩展商店页面等受保护页面无法注入防护层。
